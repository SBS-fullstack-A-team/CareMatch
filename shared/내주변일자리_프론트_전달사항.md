# "내 주변 일자리" 기능 - 프론트 작업 안내

## 참고 서비스
요양나라의 "내 주변 일자리(반경 10km)" 방식을 그대로 따라갑니다.
https://www.yoyangnara.com/plugin/recruit/near_jobs.php

## 동작 방식
1. 페이지 진입 시 브라우저 위치 권한 요청(Geolocation API) → 현재 위치 좌표 획득 → 지도 중심을 그 좌표로 이동
   - 권한 거부/실패 시: 기본 좌표(예: 서울 시청)로 대체하거나, 위치 못 찾았다는 안내 문구 표시
2. 지도를 드래그/줌해서 사용자가 원하는 위치로 이동
3. 이동이 멈추면(카카오맵 `idle` 이벤트) **자동으로** 그 위치 기준 반경 10km 내 공고를 재조회 — 버튼 클릭 필요 없음
4. 재조회 중에는 "현위치 확인 중…" 같은 로딩 표시
5. 결과가 오면 상단에 "주변 채용공고 N건" 표시 + 리스트(또는 지도 마커)로 렌더링
6. 결과 없으면 "현재 위치 주변에 채용공고가 없습니다. 지도를 이동하면 해당 지역의 채용공고가 자동으로 표시됩니다." 안내
7. 자동 갱신을 못 미더워하는 사용자를 위해 "새로고침" 버튼도 별도로 하나 둠(수동 재조회 트리거)

## 확정된 기술 스펙
- 지도 SDK: **카카오맵 JavaScript SDK**
- 반경: 고정 10km (사용자가 조절하는 슬라이더 없음, MVP 범위 밖)
- 재검색 트리거: 카카오맵 `idle` 이벤트, **400ms 디바운스** 적용 (드래그 중 API 폭주 방지)
- 리스트 카드: 기존 구인공고 카드 컴포넌트 재사용 + **거리 표시 추가** (예: "역삼동에서 1.2km") — 백엔드 응답에 `distanceKm` 필드로 내려줄 예정

## 백엔드 API (구현 예정, 명세)
```
GET /api/jobpostings/nearby?lat={lat}&lng={lng}&page={page}&size={size}
```
- `lat`, `lng`: 지도 중심 좌표 (idle 이벤트에서 얻은 값)
- `page` 기본 0, `size` 기본 20
- 응답 형식은 기존 구인공고 검색 API와 동일한 페이지네이션 구조(content, page, size, totalElements, totalPages) + 각 항목에 `distanceKm` 필드 추가 예정
- 인증 불필요(비로그인 조회 가능)

## 프론트 구현 참고 코드
```javascript
const map = new kakao.maps.Map(container, options);

kakao.maps.event.addListener(map, 'idle', debounce(() => {
  const center = map.getCenter();
  fetchNearbyJobs(center.getLat(), center.getLng());
}, 400));
```

## 확인/준비 필요 사항
- 카카오맵 API 키(JavaScript 키) 발급 필요 — 아직 없으면 발급 도와드릴 수 있음
- 기존 "구인공고" 검색 페이지와 UI/필터가 겹치지 않도록, 이 페이지는 **지도 중심 + 최소 필터**로 단순하게 구성 (일반 필터는 넣지 않음)
- "내 주변 일자리" 진입점을 별도 nav 메뉴로 유지할지, 홈 화면 버튼에서만 진입하게 할지는 별도 논의 필요(추후 결정)
