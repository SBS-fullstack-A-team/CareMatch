## 2. 운영(프로덕션) 준비도 — 이번에 서비스로 돌린다면

| 항목 | 상태 | 비고 |
|---|---|---|
| 포인트/결제 | 🔴 **전부 스텁** | `StubPointService`: 차감 항상 성공, 잔액 고정 9999. 연락처 열람(유료 기능)이 사실상 무료로 뚫려있음. 정책 확정 전이라 의도된 상태지만, 실 서비스 전엔 PG 연동 필수 |
| 회원 탈퇴 | 🔴 **API 없음** | `Member.withdraw()` 도메인 메서드는 있는데 호출하는 컨트롤러가 어디에도 없음. 법적 최소요건(개인정보보호법상 탈퇴권) |
| 약관/개인정보처리방침 내용 | 🔴 **샘플 텍스트** | `"...본문(샘플)."` 그대로. `@Profile("local")`이라 운영 DB엔 자동 시딩 안 되지만, 운영 쪽에 실제 내용 들어있는지 확인 필요 |
| CI (자동 빌드/테스트) | 🔴 **사실상 없음** | `.github/workflows/`엔 리뷰어 자동배정뿐. 어제 `main`에 병합 충돌 마커가 그대로 들어간 사고(PR #84로 수정)가 이래서 안 걸림. 프론트 `typecheck`/`build`, 백엔드 `./gradlew test`를 PR 시점에 자동으로 안 돌림 |
| 에러 모니터링 | 🟡 | Sentry 등 연동 없음. 운영 500 에러 나도 Render 로그 직접 봐야 앎 |
| 레이트리밋/캡챠 | 🟡 | 로그인은 5회 실패 잠금 있음. `/api/verifications/send`(인증코드 발송)·회원가입은 무제한 호출 가능 — 스팸 발송/무차별 계정 생성 벡터 |
| 자격증 진위 검수 | 🟡 | 파일 존재/크기/확장자만 자동 체크(스토리지 stub이라 항상 통과). 사람이 자격증 내용을 확인하는 절차 없음. 시설 사업자등록증은 admin 승인 있음 |
